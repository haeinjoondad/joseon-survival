# 조선 관리 생존기

> 조선 조정에 첫 출근한 말단 관리가 공적, 녹봉, 평판, 멘탈, 체력을 관리하며 영의정까지 올라가는 모바일 방치형 생존 게임입니다.

배포 URL: https://joseon-survival-9sjk.vercel.app

`main` 브랜치에 push하면 Vercel에서 자동 배포됩니다.

---

## 게임 개요

플레이어는 말단 관리로 시작합니다. 상소문을 작성해 공적을 쌓고, 민원을 처리해 평판을 회복하며, 의정부 회의로 정치력을 키웁니다.

업무를 계속하면 공적과 녹봉은 늘지만 멘탈과 체력이 줄어듭니다. 왕심, 장부 조작, 감찰, 이벤트, 승진 확률을 함께 고려해 위험을 감수할지 안정적으로 성장할지 선택하는 구조입니다.

시작 시에는 짧은 프롤로그를 문단별로 넘기며 게임 분위기를 잡고, `출근하기` 버튼 이후 이름을 정해 게임을 시작합니다.

## 현재 구현된 핵심 기능

### 진행 루프

- 1초 tick 기반 자동 진행
- 현재 선택 업무에 따라 공적, 녹봉, 평판, 멘탈, 체력 변화
- 업무별 성장 스탯 자동 경험치 획득
- 멘탈 0 도달 시 파직 처리
- 체력 30 미만이면 공적 획득 -20%, 체력 0이면 -50%
- 녹봉을 써서 멘탈/체력 회복 가능

### 업무

| 업무 | 역할 | 주요 효과 |
|------|------|-----------|
| 상소문 작성 | 공적 중심 업무 | 필력 기반 공적 증가, 왕심 영향 적용 |
| 민원 처리 | 평판 회복 업무 | 공적/녹봉 증가, 시간당 평판 증가, 체력 소모 큼 |
| 의정부 회의 | 정치력 성장 업무 | 정치력 성장, 멘탈 소모 큼 |

업무 카드에는 실제 tick 계산과 맞춘 공적/초, 녹봉/초, 멘탈/분, 체력/분, 평판/시간, 성장 스탯이 표시됩니다.

### 자원과 스탯

- 공적: 승진에 필요한 핵심 점수
- 녹봉: 회복, 강화, 성장에 쓰는 재화
- 평판: 승진 조건과 승진 확률에 영향을 주는 상한 100 자원
- 멘탈: 0이 되면 파직
- 체력: 낮아지면 공적 생산 효율 감소
- 필력: 상소문 작성 효율 증가
- 눈치: 민원 처리 성장 스탯, 이벤트 위기 회피에 사용
- 정치력: 의정부 회의 성장 스탯, 승진 확률 보정

### 장비 강화

| 장비 | 효과 |
|------|------|
| 붓 | 강화 1회당 공적 획득 +5% |
| 책상 | 강화 1회당 공적/녹봉 획득 +3% |
| 관복 | 강화 1회당 평판 +0.25/시간, 민원 처리 중 평판 획득 +2% |

강화 비용과 현재 효과는 성장 탭의 카드에 표시됩니다.

## 왕심 시스템

왕심은 조정의 분위기를 나타내는 전역 상태입니다. 정각/30분 슬롯이 바뀔 때 갱신됩니다.

| 왕심 | 상소문 공적 | 멘탈 소모 | 승진 보정 | 감찰 위험 |
|------|-------------|-----------|-----------|-----------|
| 흐뭇 | x1.15 | x0.9 | +5% | -5% |
| 평온 | x1.0 | x1.0 | 0% | 0% |
| 불편 | x1.4 | x1.2 | -3% | +5% |
| 격노 | x2.2 | x1.5 | -8% | +12% |

왕심은 상소문 작성, 승진 확률, 장부 조작 감찰 위험에 영향을 줍니다.

---

## 장부 조작과 감찰

장부 조작은 공적 획득을 3배로 올리는 고위험 선택입니다.

- 장부 조작 ON: 공적 x3
- 조작 중 의심도 상승
- 조작 OFF: 의심도 자연 감소
- 의심도 70 이상에서 적발되면 강등 가능
- 적발 시 장부 조작 OFF, 의심도 0, 공적/녹봉/멘탈/평판 손실

감찰은 일반 이벤트와 겹치지 않도록 분리되어 있습니다.

- 일반 이벤트: 정각/30분
- 장부 조작 감찰: 15분/45분

감찰 확률 공식:

```text
감찰 확률 = 기본 5% + 의심도 × 0.5% + 왕심 보정
최종값은 5%~80%로 제한
```

업무 탭의 장부 조작 카드에는 다음 감찰까지 남은 시간, 현재 의심도, 예상 위험도, 왕심 보정이 표시됩니다. UI 표시 확률과 실제 판정은 같은 함수와 같은 상수를 사용합니다.

## 평판 시스템

평판 최대치는 100입니다.

획득:

- 관복 강화 패시브: 강화 1회당 +0.25/시간
- 민원 처리: 기본 +3/시간
- 관복 강화 1회당 민원 처리 평판 획득 +2%
- 일부 이벤트 보상

소모/손실:

- 승진 성공 시 도달 품계의 요구 평판 50% 차감
- 장부 조작 적발 시 평판 손실
- 일부 이벤트 선택 결과

승진 성공 시 기존의 평판 +10 보상은 제거되었습니다.

---

## 승진 시스템

품계는 종9품 참봉부터 정1품 영의정까지 18단계입니다.

승진 조건:

- 다음 품계의 요구 공적
- 다음 품계의 요구 평판

승진 성공률:

```text
기본 40%
+ 초과 공적 보너스 최대 30%
+ 평판 보너스 최대 20%
+ 정치력 보너스 최대 10%
+ 왕심 보정
```

승진 결과:

- 성공: 다음 품계로 승진, 공적 0, 도달 품계 요구 평판의 50% 차감
- 실패: 공적 10% 손실
- 평판은 0~100 범위로 유지

## 이벤트

- 튜토리얼 첫 이벤트 1개
- 일반 랜덤 이벤트 20개 이상
- 이벤트는 정각/30분 슬롯 기준으로 발생 시도
- 최근 3개 이벤트 반복 방지
- 선택지에 따라 공적, 녹봉, 멘탈, 체력, 평판, 스탯 경험치가 변동
- 일부 선택지는 필력/눈치/정치력 체크를 사용

이벤트 결과 모달에는 실제 적용된 효과가 표시됩니다.

---

## 오프라인 보상

- 최대 8시간까지 오프라인 진행 계산
- 멘탈이 10까지 떨어지면 오프라인 업무 중단
- 오프라인으로 즉시 파직되지는 않음
- 30초 이상 이탈하면 진행도는 반영
- 5분 이상 이탈했을 때만 부재중 업무 보고 모달 표시
- 모바일 Chrome 백그라운드에서 tick이 저장 시각을 덮어써 보상이 1분으로 잘리는 문제를 방지

## 저장과 계정

### 게스트 저장

- 로그인 없이 LocalStorage에 저장
- 현재 기기와 브라우저에 종속

### 계정 저장

- Supabase Auth 사용
- 이메일/비밀번호 가입 및 로그인
- 게임 중간에도 계정 생성 가능
- 게스트로 진행하던 데이터를 계정에 연결 가능
- 계정 저장본과 현재 기기 저장본이 다르면 선택 UI 표시
- 플레이 중 5초 단위로 클라우드 저장 동기화

## 개발

```bash
npm install
npm run dev
npm run build
npm run preview
```

Supabase 계정 저장을 사용하려면 환경 변수가 필요합니다.

```bash
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

테이블 생성과 RLS 설정은 `supabase/schema.sql` 및 `SUPABASE_SETUP.md`를 참고합니다.
