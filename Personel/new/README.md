# 조선 관리 생존기

> 종9품 참봉에서 정1품 영의정까지, 살아남는 자가 승진한다.

조선시대 관료제를 현대 직장인 감성으로 재해석한 모바일 방치형 생존 게임입니다.

---

## 플레이

**배포 URL:** https://joseon-survival-9sjk.vercel.app

---

## 게임 소개

말단 관리로 시작해 상소문 작성, 민원 처리, 의정부 회의, 파벌 정치, 야근을 버티며 영의정까지 승진하는 세로형 방치 생존 게임입니다.

- 상소문 = 보고서
- 왕명 = 대표 지시
- 사헌부 감찰 = 감사팀
- 유배 = 지방 발령
- 멘탈 0 = 사직서

## 구현된 기능

### 핵심 루프

- **방치 생산**: 1초 tick, 선택한 업무에 따라 공적/녹봉 자동 증가
- **오프라인 보상**: 최대 8시간치 부재 보상 계산
- **오프라인 업무 중단**: 오프라인 중 멘탈이 10에 도달하면 업무 중단, 사직은 방지
- **자원 5종**: 공적, 녹봉, 멘탈, 체력, 평판
- **능력치 3종**: 필력, 눈치, 정치력
- **장비 3종**: 붓, 책상, 관복
- **품계 18단계**: 종9품 참봉 → 정1품 영의정

### 저장/로그인

- **게스트 모드**: 로그인 없이 브라우저 LocalStorage에 저장
- **계정 모드**: Supabase 로그인 후 계정별 저장 데이터 동기화
- **게스트 → 계정 전환**: 로그인 시 현재 진행도를 계정에 저장 가능
- **저장본 충돌 처리**: 현재 기기 저장본과 계정 저장본이 다르면 선택 UI 표시
- **자동 저장**: 플레이 중 약 5초 단위로 Supabase에 계정 저장

### 이벤트/UI

- **이벤트 20개**: 조건부 이벤트와 스탯 판정 분기
- **이벤트 발생 시점**: 매시 정각/30분 슬롯 기준
- **중복 방지**: 최근 3개 이벤트 재발생 차단
- **캐릭터 상태 표시**: 멘탈/체력에 따라 표정과 상태 문구 변화
- **승진 축하 연출**: 황금빛 오버레이, 파티클, ping 애니메이션
- **게임오버 화면**: 사직서 형태, 최종 품계별 엔딩 문구
- **튜토리얼**: 4단계 배너 가이드와 첫 이벤트

## 게임 시스템 상세

### 승진 성공률

```text
성공률 = 기본 40%
       + 공적 보너스 (최대 +30%)
       + 평판 보너스 (최대 +20%)
       + 정치력 보너스 (최대 +10%)
```

- 승진 성공 시 다음 품계로 승진, 공적 0, 평판 +10
- 승진 실패 시 공적 10% 소모

### 장비 효과

| 장비 | 효과 |
|------|------|
| 붓 | 강화 1회당 공적 획득 +5% |
| 책상 | 강화 1회당 공적/녹봉 획득 +3% |
| 관복 | 강화 1회당 평판 자동 상승 +0.72/시간 |

### 체력 패널티

| 체력 | 공적 생산 |
|------|-----------|
| 30 이상 | 정상 |
| 30 미만 | -20% |
| 0 | -50% |

### 회복 비용

- 탕약 복용: 멘탈 +30, 녹봉 50냥
- 잠깐 휴식: 체력 +30, 녹봉 50냥

### 오프라인 보상

- 최대 8시간까지 계산
- 오프라인 중 멘탈이 10까지 떨어지면 업무를 멈춤
- 복귀 모달에 실제 업무 시간과 중단 사유 표시
- 오프라인으로 인한 즉시 사직은 발생하지 않음

## Supabase 설정

계정 저장을 사용하려면 Supabase 프로젝트와 Vercel 환경변수가 필요합니다.

필요한 환경변수:

```bash
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```

Supabase SQL Editor에서 `supabase/schema.sql`을 실행합니다.

자동 노출을 끈 프로젝트에서는 아래 권한도 필요합니다.

```sql
grant usage on schema public to anon, authenticated;

grant select, insert, update
on public.game_saves
to authenticated;
```

자세한 절차는 `SUPABASE_SETUP.md`를 참고합니다.
