# 조선 관리 생존기

> 종9품에서 영의정까지, 살아남는 자가 승진한다.

조선시대 관료제를 현대 직장인 감성으로 재해석한 모바일 방치형 생존 게임.

---

## 플레이

**배포 URL:** https://joseon-survival-9sjk.vercel.app

---

## 게임 소개

말단 관리로 시작해 상소문 작성·민원 처리·파벌 정치·야근을 버티며 영의정까지 승진하는 세로형 방치 생존 게임.

- 상소문 = 보고서
- 왕명 = 대표 지시
- 사헌부 감찰 = 감사팀
- 유배 = 지방 발령
- 멘탈 0 = 사직서

## 구현된 기능

### Phase 1 — 핵심 루프
- **방치 생산**: 1초 tick, 업무 선택에 따라 자원 자동 증가
- **오프라인 보상**: 최대 8시간치 부재 보상 자동 계산
- **자원 6종**: 공적 · 녹봉 · 멘탈 · 체력 · 평판
- **능력치 3종**: 필력 · 눈치 · 정치력 (강화 + 업무별 자동 경험치)
- **장비 3종**: 붓 · 책상 · 관복 (녹봉으로 강화)
- **품계 15단계**: 종9품 참봉 → 정1품 영의정
- **LocalStorage 자동 저장**

### Phase 2 — 이벤트 시스템
- **이벤트 20개**: 기획서 목록 전체 구현
- **발생 시점**: 매시 정각·30분 (시계 기준, 로그인 시간 무관)
- **스탯 판정**: 선택지에 필력·눈치·정치력 기준치 표시 → 성공/실패 분기
- **조건부 이벤트**: 품계·멘탈 수치에 따라 발생 여부 결정
- **중복 방지**: 최근 3개 이벤트 재발생 차단

### Phase 3 — UI/비주얼
- **캐릭터 표시 영역**: 멘탈 수치에 따라 표정 변화 (😊→😔→😵→💀)
- **품계 뱃지**: 하급(회색) → 중간(녹색) → 6품(파랑) → 당상관(보라) → 판서급(주황) → 의정(금색)
- **승진 축하 연출**: 황금빛 오버레이 + 파티클 + ping 애니메이션
- **게임오버 화면**: 사직서 형태, 최종 품계별 11종 엔딩 문구
- **튜토리얼**: 4단계 배너 가이드 + 탭바 하이라이트 + 첫 이벤트 강제 발생

### Phase 4 — 배포
- **Vercel 배포** 완료 (`joseon-survival-9sjk.vercel.app`)
- **GitHub 연동**: `main` 브랜치 push 시 자동 배포

## 게임 시스템 상세

### 승진 성공률 계산
```
성공률 = 기본 40%
       + 공적 보너스 (최대 +30%)
       + 평판 보너스 (최대 +20%)
       + 정치력 보너스 (최대 +10%)
```
- 승진 성공 시 공적 전량 소모, 평판 +10
- 승진 실패 시 공적 10% 소모

### 체력 패널티
| 체력 | 공적 생산 |
|------|-----------|
| 30 이상 | 정상 |
| 30 미만 | -20% |
| 0 | -50% |

### 회복 비용
- 탕약 복용 (멘탈 +30): **녹봉 50냥**
- 잠깐 휴식 (체력 +30): **녹봉 50냥**

### 멘탈 0 → 게임오버
멘탈이 0에 도달하면 사직서 화면으로 전환. 최종 품계별 엔딩 문구 11종.

## 프로젝트 구조

```
src/
├── types/
│   ├── game.ts          # Player, WorkType, Stats, Equipment 타입
│   └── event.ts         # GameEvent, EventChoice, EventEffect 타입
├── data/
│   ├── ranks.ts         # 품계 15단계 데이터 (종9품~정1품 영의정)
│   ├── works.ts         # 업무 3종 데이터
│   └── events.ts        # 이벤트 20개 데이터
├── store/
│   ├── useGameStore.ts  # 게임 상태·로직 전체 (tick, 승진, 이벤트 등)
│   └── useTutorial.ts   # 튜토리얼 단계 추적
└── components/
    ├── StartScreen.tsx          # 시작 화면 (이름 입력)
    ├── StatusBar.tsx            # 상단 자원 표시
    ├── CharacterDisplay.tsx     # 캐릭터 + 멘탈 상태 표시
    ├── WorkPanel.tsx            # 업무 선택 + 회복 버튼
    ├── StatsPanel.tsx           # 능력치·장비 강화
    ├── PromotionPanel.tsx       # 승진 심사
    ├── PromotionCelebration.tsx # 승진 축하 연출
    ├── EventModal.tsx           # 이벤트 + 결과 모달
    ├── OfflineRewardModal.tsx   # 오프라인 보상 모달
    ├── TutorialBanner.tsx       # 튜토리얼 배너
    └── GameOverScreen.tsx       # 사직서 화면 (11종 엔딩)
```
